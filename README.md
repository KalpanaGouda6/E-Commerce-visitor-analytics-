# E-Commerce Visitor Analytics

A web application that tracks visitors on an e-commerce site and shows the data on a dashboard.

## Features
- Landing page for the e-commerce site
- Dashboard to view visitor analytics
- Database module to store visitor data

## Tech Stack
- Python [add Flask / Django if used]
- [MySQL / PostgreSQL / SQLite: whichever db.py uses]
- HTML, CSS (E commerce-ui folder)

## Project Structure
- app.py: main application
- landing.py: landing page
- dashboard.py: analytics dashboard
- db.py: database connection
- E commerce-ui/: front-end files

## How to Run
1. Install Python and the required libraries
2. Run: python app.py
3. Open the local address shown in the terminal
